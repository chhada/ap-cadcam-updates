# AP Cad/Cam updates

Alpha Precision's CAD/CAM app for Windows. The app's **Update** button reads `latest.json` here
and downloads the newest version. Only the finished app is in this repository.

## First install

1. Download [ap-cadcam-windows-x64.zip](https://github.com/chhada/ap-cadcam-updates/raw/main/ap-cadcam-windows-x64.zip).
2. Right-click it, choose **Extract All**, and open **AP-CadCam.exe**.
3. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**
   (the program is not signed).

## Versions

### 1.0.1 (2026-11-11)

- New look: gray top bar and panels with light-blue highlights (theme "AP Gray Blue").
  Other themes, Dark included, are still in Preferences > Appearance.

### 1.0.0 (2026-11-11)

- The app is now called AP Cad/Cam.
- New **Comment** button at the top right: send a Bug, a Feature request or an Improvement idea.
- New **Update** button: it appears at the top when a newer version is on this page.
- Includes all CAM work so far: tool library, mill and lathe setups, 2D and 3D milling,
